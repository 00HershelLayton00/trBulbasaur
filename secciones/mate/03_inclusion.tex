\subsection{Inclusión-exclusión}\label{rec:ie}

\[
\left|\bigcup_{i=1}^{n}A_i\right|
=\sum_i|A_i|-\sum_{i<j}|A_i\cap A_j|
+\sum_{i<j<k}|A_i\cap A_j\cap A_k|-\cdots
\]

Para contar “al menos una propiedad”, recorre las máscaras no vacías y suma
con signo según el número de bits:

\begin{lstlisting}
ll ans=0;
for(int mask=1;mask<(1<<n);++mask){
  int b=__builtin_popcount(mask);
  ans+=(b&1?1:-1)*f(mask);  // f(mask) = interseccion de esas propiedades
}
\end{lstlisting}
